💡 ¿Cómo actualizar un documento? Sube el archivo a Google Drive → clic derecho → Compartir → "Cualquiera con el enlace puede ver" → copia el enlace → abre el archivo index.html → busca la escuela y el documento → pega el enlace en url_ver y cambia el estado a "entregado" → guarda y vuelve a subir a GitHub.
